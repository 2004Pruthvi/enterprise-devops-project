## Reporting a Vulnerability

Security is a fundamental priority for cloud-native and platform infrastructure.

If you discover any security vulnerability, exposed credential, or configuration flaw in this repository:
1. **Do not create a public GitHub issue.**
2. Please report the issue confidentially by email to:
   **[pruthviraj462004@gmail.com](mailto:pruthviraj462004@gmail.com)**
3. Please include:
   - Description of the vulnerability and its potential impact
   - Exact steps or reproduction script
   - Affected files and components

I will review the report promptly and coordinate remediation before any public disclosure.
